# Мониторинг минимальных цен и сравнение товаров 24/7 (v2.8.2)

Автоматический сервис поиска минимальных реальных цен, учёта внутренней таможенной пошлины с карточек и оценки **Цена / Качество** по схеме **«1 позиция → 6 маркетплейсов»**. Работает круглосуточно через Telegram-бота, облачный конвейер GitHub Actions или локально на ПК под управлением Windows.

---

## 1. Схема сканирования: 6 магазинов на 1 позицию

Для каждой активной товарной позиции в списке бот последовательно проходит все **6 площадок** и отображает прогресс в одном обновляемом сообщении Telegram:

| № | Площадка | Особенности сбора и фильтрации |
| :-: | :--- | :--- |
| 1 | **Ozon** | Сортировка по минимальной цене (`&from_global=true`), чтение реальной пошлины с карточки, очистка названий от промо-бейджей |
| 2 | **AliExpress** | Автопересчёт цен и чтение фактической пошлины с карточки, отсев аксессуаров/пустых лотов |
| 3 | **Яндекс Маркет** | Поиск с учётом кода региона (`ymarket_lr`) и считыванием пошлины с карточки |
| 4 | **Авито** | Геолокационный радиус **5–15 км** (самовывоз) + фильтр **«📍 Самовывоз / 🚚 Доставка»** без заглушек |
| 5 | **DNS** | Наличие в рознице и на складе региона, прогрев антибот-защиты |
| 6 | **Wildberries** | Актуальная цена кошелька/карты, чтение реальной пошлины и рейтинга продавца |

### Живые индикаторы поиска
Во время прохода после нажатия **«🔍 Поиск новых цен»** статус каждой позиции и каждого её магазина меняется в реальном времени:
* `🔄` — идёт поиск и сверка карточек в конкретном магазине;
* `⏳` — магазин ожидает своей очереди по данной позиции;
* `✅ N поз.` — сбор завершён, найдены предложения;
* `❌ 0 поз.` — подходящие лоты по заданным фильтрам не найдены или площадка не ответила;
* `⬜ отключён` — магазин снят пользователем в настройках;
* возле номера самой позиции (`1.`, `2.`, …) после прохода всех 6 магазинов выставляется общий итог: **`✅ (всего K поз.)`** или **`❌ (0 поз.)`**.

## 2. Внутренняя пошлина с сайта, анти-хлам фильтр и сверка карточек

* **Пошлина берётся только с карточки товара и точно суммируется с ценой:** бот не вычисляет сборы «из головы» по формулам. После сбора выдачи система параллельно (по выделенной вкладке на каждую площадку, в рамках жёсткого лимита до **90 сек**) открывает **карточки собранных товаров** (приоритетно топ-6 по каждому запросу и магазину), считывает актуальную цену и внутреннюю таможенную пошлину прямо с сайта в блоке цены/доставки (включая формулировку `доплата за таможенный платёж` на Ozon), отсекая карусели похожих товаров, и явно складывает **Итого = Цена витрины + Пошлина** (с живой формулой `=J+K` в Excel, `✔ проверено на карточке`).
* **Региональные цены, прямой Авито без прокси и кнопка обновления:** цены Wildberries (`dest`), Яндекс Маркета (`yandex_gid` / `lr`) и геолокация подстраиваются под выбранный город/координаты, история цен ведётся раздельно по регионам, под отчётами есть кнопка **«🔄 Обновить цены (регион)»**, а Авито при сбое прокси автоматически переключается на прямой канал (`avito.ru` / `avito.st`, `m.avito.ru` и резервный Chrome без прокси).
* **Универсальный отсев деталей, расходников и хлама:** помимо рассрочек и фейковых скидок, для **любых тем** (мебель, бытовые приборы, электроника, канцелярия и т.д.) отсекаются китайские основания/подносы/подшипники/насадки/фильтры/стержни — как по словарю и связкам предлогов («для / от / к + товар»), так и по аномальному выбросу цены ниже рыночной медианы.
* **Гарантированная доставка Excel (`.xlsx`):** после каждого сканирования таблица отправляется в Telegram до 3 раз с проверкой ответа API и изолирована от сбоев текстовых блоков; длинные ссылки (Яндекс Маркет, Ozon, AliExpress) очищаются от трекинг-хвостов.
* **Цветовая маркировка в отчётах и Excel (`Мониторинг_Товаров.xlsx`):**
  * 🟢 **Зелёная** — оптимальная реальная цена, высокий рейтинг и наличие;
  * 🟡 **Жёлтая** — есть нюанс (под заказ, мало отзывов, стоит перепроверить описание);
  * 🔴 **Красная** — продано / несоответствие модели / откровенная деталь или замануха.

## 3. Функции Telegram-бота (разделённое меню и команды)

При первом запуске и по команде `/start` (`/help`) описание отправляется **четырьмя отдельными карточками** (площадки → алгоритм поиска → геолокация и автоуведомления → текущие персональные настройки) без перегруженных «простыней» текста.

* **`/items` («📦 Мои товары»)** — управление списком отслеживаемых позиций: включение в поиск `✅/⬜`, персональные уведомления `🔔/🔕`, точечная замена `✏️`, удаление `❌`, очистка снятых позиций (`🗑 Убрать снятые ⬜`) и создание нового списка.
* **`/replace` («🔄 Заменить один товар»)** — быстрая замена ровно одной позиции в списке (например, «кресла» при большом Excel), не затрагивая остальные товары.
* **`/compare` («⚖️ Сравнение Цена/Качество»)** — оформленный рейтинг предложений между 6 магазинами с чистыми ссылками, фильтрацией по конкретному товару и безопасным разбиением длинных отчётов без обрыва HTML.
* **`/city` («📍 Сменить город»)** — выбор региона вручную, радиуса Авито (**5 / 10 / 15 км**), режима (**Самовывоз / Доставка / Всё**) или мгновенная отправка геолокации 📱 (моментальное определение города/района).
* **`/shops` («🏬 Выбор магазинов»)** — включение или отключение любой из 6 площадок (`✅/⬜`).
* **`/price` («💰 Задать цену (ОТ и ДО)»)** — ручной диапазон цен или автоматический подбор по категории товара.
* **`/notify` («🔔 Уведомления и интервал»)** — режим оповещений (`🟢 Только выгодные`, `🔔 Все 🟢+🟡`, `🔕 Тихий режим`) и интервалы проверки: по умолчанию строго **каждые 3 часа** (с возможностью выбрать другой интервал от 15 мин до 1 недели или циклический режим `3 часа ⇄ 1 день`).
* **`/scan` («🔍 Поиск новых цен»)** — внеочередной запуск полного обхода по всем выбранным товарам.
* **`/top` («📋 Лучшие цены по магазинам»)** и **`/excel` («📥 Скачать Excel (.xlsx)»)** — быстрая сводка выгодных цен в чате (с кнопками фильтра Авито) и выгрузка таблицы строго для выбранного региона и актуальной даты.
* **`/changelog`** — список нововведений текущей версии бота.

## 4. Облачный режим 24/7 (GitHub Actions)

Конвейер [.github/workflows/monitor.yml](.github/workflows/monitor.yml) работает на базе `windows-latest` с бесшовным перезапуском каждые 5.5 часов:
1. Устанавливает московский часовой пояс (`Russian Standard Time`) и российский браузер **`Chromium-Gost`** (с автоматическим резервом на системный Chrome).
2. Поднимает локальный мост `DirectWifiProxyBridge` (`wifi_bridge.py`), который маршрутизирует запросы к российским маркетплейсам через ваш секретный узел `NET_NODE` (`socks5h://`, `socks5://`, `http://` или `host:port:user:pass`), отсекает сторонние рекламные трекеры и не допускает утечки зарубежного IP на защищённые магазины РФ при кратковременных задержках канала.
3. Шифрованно сохраняет пользовательские настройки, выбранный регион и таймер сканирования между перезапусками облачных смен (в зашифрованном кэше Actions, а при задании `STATE_GIST_TOKEN` и `STATE_GIST_ID` — также через приватный Gist).

### Необходимые Secrets репозитория (`Settings → Secrets and variables → Actions`)
* `TG_BOT_TOKEN` — токен бота от `@BotFather` *(обязательно)*;
* `TG_CHAT_ID` — базовый chat ID получателя при первом запуске *(опционально)*;
* `TG_ALLOWED_CHATS` — список разрешённых ID через запятую *(опционально; если пусто, бот открыт для всех пользователей, у каждого свой профиль)*;
* `NET_NODE` — прокси-узел РФ (`socks5://user:pass@ip:port`, `http://...` или `ip:port:user:pass`) *(рекомендуется для облака)*;
* `STATE_GIST_TOKEN` и `STATE_GIST_ID` — токен (право `gist`) и ID приватного Gist для сохранения пользовательских настроек между перезапусками облачных смен.

## 5. Локальный запуск (Windows) и `config.json`

1. Установите зависимости (Python 3.10+):
   ```bash
   pip install httpx websockets rich
   ```
2. Установите `Chromium-Gost` или обычный Google Chrome (для Windows доступен прямой физический канал через Wi-Fi при `"bypass_vpn_proxy": true` или внешний узел через `NET_NODE`).
3. Запустите двойным кликом **`ЗАПУСК_МОНИТОРИНГА.bat`** (`START_MONITOR.bat`) или выполните:
   ```bash
   python main.py --headless
   ```

Базовые параметры по умолчанию задаются в [config.json](config.json):
```json
{
  "queries": ["ноутбук ryzen 5 7640hs", "ноутбук ryzen 7 8845hs", "кресло компьютерное"],
  "price_is_custom": false,
  "bypass_vpn_proxy": true,
  "interval_minutes": 180,
  "use_ladder": false,
  "shops_priority": {
    "ozon": true,
    "aliexpress": true,
    "ymarket": true,
    "avito": true,
    "dns": true,
    "wb": true
  }
}
```
